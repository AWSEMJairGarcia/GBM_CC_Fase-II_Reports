# GBM CC Fase II — Sprint Dashboard

Dashboard de reportes y visualización de sprints para el proyecto GBM Amazon Connect Fase II.

## Features
- Conexión en tiempo real con Jira Cloud API
- Progreso por Sprint (barras de %)
- Progreso por Épica
- Lista de tareas completadas y en progreso
- Diseño dark theme con branding GBM | AWS

## Setup
1. Abre `index.html` en un servidor (GitHub Pages o localhost)
2. Ingresa tu email y API token de Jira la primera vez
3. Los datos se cargan automáticamente
