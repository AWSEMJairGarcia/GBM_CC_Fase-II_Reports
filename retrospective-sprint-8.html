02 Decisiones & hallazgos técnicos
Task ID de Salesforce: la creación será asíncrona pero debe devolver el Task ID. Eduardo Godínez confirmó que la Task no tiene folio; el ID retornado en la inserción permite armar el enlace directo al registro desde el workspace. A revisar por Nubity cómo exponerlo.

Campo "type" (canal): Eduardo Godínez hará visible el campo type para reportería (chat entrante, llamada entrante/saliente), independiente del asunto que el usuario pueda cambiar.

Latencia de identificación: en DEV la consulta es rápida (candidatos < 1 M ≈ 1–3 s); en producción con ~3 M de clientes puede llegar a 20–30 s, motivo por el que existe la API Entidad Cliente. Considerar la diferencia en las pruebas.

Doble registro por timeout: consultas a Salesforce > ~5 s daban timeout y el fallback creaba la Task dos veces; ya se ajustó. Mantener bajo observación.
