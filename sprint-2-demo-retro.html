04 Retrospectiva

Qué funcionó bien

  • 81% de completitud (77/95 tickets Done) manteniendo calidad.
  • Dos entregables listos para producción: API Queen en Stage y Mixpanel validado E2E.
  • Colaboración directa GBM-Nubity: Brenda y Rich integrados a pruebas, menos triangulación.
  • Nivelación de entornos Dev/Stage/Prod completada — base para despliegues confiables.

Qué podemos mejorar

  • Dependencias del entorno GBM frenan pruebas (carga QA, datos de prueba EC).
  • Trazabilidad de validaciones: comentarios de Brenda deben ser tareas, no chat.
  • Hallazgos de seguridad fuera de scope (rotación keys, WAF, Resource Policy) siguen en estimación.
  • Coincidencias dinámicas en EC: definir manejo cuando la búsqueda devuelve múltiples resultados.

Action Items - Sprint 3

  • Pasar API Queen a Producción (martes/miércoles) → luego Mixpanel a Stage.
  • Crear user story de pruebas para trackear validaciones de Brenda.
  • Canalizar datos de prueba EC con GBM (AC-807, Abigail).
  • Desbloquear número WhatsApp DEV para pruebas E2E.
